# Rubric map

| Criterion | Reviewable implementation |
|---|---|
| OCR & Information Extraction | Embedded PDF words, Tesseract fallback, INR/date normalization, unverified confidence and page boxes. |
| Document Understanding | Keyword classification, missing/duplicate fields, format, chronology, age and payroll arithmetic checks. |
| Visual Forensic Analysis | Amount typography, compression residual, ORB translation, signature SSIM, hidden PDF spans and retained revisions. |
| Contextual Intelligence | Name variants, identity and address comparisons, pay-cycle correlation, tolerance and bank credit conflict. |
| Evidence & Traceability | Evidence IDs, original region overlays, related fields, SHA-256, chained event log and dossier. |
| AI Reasoning & Explainability | Deterministic evidence-linked statements, plausible harmless explanations, specific verification requests and explicit concern weights. |
| Technical Implementation | React/TypeScript and FastAPI, bounded native workers, SQLite, Docker, tests, and reproducible benchmarks. |
| Innovation | Peel the Layer reconstructs earlier PDF bytes. The Innocent Explanation panel and reviewer action workflow keep uncertainty and due process visible. |
